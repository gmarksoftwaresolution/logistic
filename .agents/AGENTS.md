# Project Behavioral Rules & User Directives

- **Target App Scope**: Only make changes within the **Transporter App** (`apps/transporter-app` and `backend/transporter`). Do NOT modify other applications or backend modules unless explicitly instructed by the user.
- **Data & Safety Protection**: Do NOT run commands, migrations, seeds, or scripts that reset, wipe, truncate, or lose database data, nor make unexpected logic changes.
